Local Triage

Local email categorization and importance ranking

Behaviour

Model

The quantized model is downloaded once and cached by the native Windows companion. Inference runs outside Thunderbird so its background process remains responsive. Message contents never leave this computer.

Categories

Calendar event model

Deterministic extraction owns the event date, time, duration, and location. A local model writes concise English or Turkish titles and descriptions. On Windows, Qwen3.5 0.8B runs through the native CPU companion (approximately 668 MB, Q4 with FP32 activations). The model is cached locally, concurrent requests share one load, and English and Turkish output are validated before it is accepted.

Event model diagnostics

Includes native runtime stages for both models, local cache activity, CPU details, and worker health. Email subjects and bodies are not included.
